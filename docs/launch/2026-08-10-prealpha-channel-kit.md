**Body (Download live):**
```text
SimpleMark opens a local Markdown file as a finished document — not a source pane with a preview bolted on.

Your agent (Codex, Claude, etc.) writes plan.md. SimpleMark makes that exact file worth reading: Mermaid, Vega-Lite, Graphviz, math, tables, ANSI/terminal evidence, and prose on one calm page. When something needs a fix, you correct that block; untouched source stays byte-identical. The native macOS app watches the file so external writes refresh without turning into a cockpit.

Always rendered. Always your file. No vault, no account.

This is pre-alpha (macOS first). Typora-class editors help you write Markdown; SimpleMark is for judging what agents already wrote.
```
