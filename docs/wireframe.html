  sniff(input) {
    if (!DIAGRAM_HEAD.test(input.text)) return null
    try { mermaid.parse(input.text) }

    return node('mermaid', input.text)

Details that decide whether it feels trustworthy

Three behaviors separate “magic” from “a trick that occasionally eats my notes.”

Failure is visible and local

Broken diagram source never renders a blank rectangle. The block shows the parser’s own message and the source stays editable in place.

Diagram didn’t parse
Parse error on line 4: expected node id, got '-->'

Text that merely looks like Mermaid but fails to parse is left as plain text — no conversion, no surprise.

Typography lives in Preferences

Bear-style: you choose the face for your notes, the toolbar handles structure and emphasis. Per-word fonts can’t exist in a .md file, and Bear doesn’t have them either.
